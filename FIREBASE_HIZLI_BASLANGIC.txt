┌──────────────────────────────────────────────────────────────────────────────┐
│ ADIM 2: Realtime Database Rules'a Git                                       │
└──────────────────────────────────────────────────────────────────────────────┘

   Sol menü → Build → Realtime Database
   
   Üst menü → Rules sekmesi


┌──────────────────────────────────────────────────────────────────────────────┐
│ ADIM 3: Rules'u Kopyala ve Yapıştır                                         │
└──────────────────────────────────────────────────────────────────────────────┘

   1. firebase.rules.json dosyasını aç
   2. İçeriği TAMAMEN kopyala (Ctrl+A → Ctrl+C)
   3. Firebase Console'daki eski rules'u SİL
   4. Yeni rules'u YAPIŞTIR
   5. Sağ üstteki "Publish" butonuna tıkla
   6. 10 saniye bekle


┌──────────────────────────────────────────────────────────────────────────────┐
│ ADIM 4: Test Et                                                             │
└──────────────────────────────────────────────────────────────────────────────┘

   Terminal'de çalıştır:
   
   $ node scripts/check-firebase.js
   
   Başarılı çıktı:
   ✅ Okuma izni çalışıyor
   ✅ Yazma koruması çalışıyor
   🎉 Firebase Rules başarıyla aktif!


┌──────────────────────────────────────────────────────────────────────────────┐
│ ADIM 5: Uygulamada Test Et                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

   1. Uygulamayı aç
   2. "Online Çok Oyunculu" seç
   3. Adını yaz ve zorluk seç
   4. "Oda Oluştur" butonuna tıkla
   5. Oda kodu görünecek (örn: 123456)
   6. Başka cihazdan aynı kodu ile katıl
   7. Mesaj gönder ve oyunu oyna

      → Rules'u doğru yapıştırdığından emin ol
      → Publish'e tıkladığından emin ol
      → 10 saniye bekle ve tekrar dene

   ❌ Oda oluşturulamıyor:
      → Firebase Console → Data sekmesi
      → Eski test odalarını manuel sil
      → Yeni oda oluştur

   ❌ Test script çalışmıyor:
      → İnternet bağlantını kontrol et
      → node --version (v14+ olmalı)
